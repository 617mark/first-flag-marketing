Case Study: Loonen, Inc. Test Result System

Custom AI Data & Document Workflow

A look at a custom web application built for Loonen to eliminate manual data entry and summarize lab report analytics in real time.

The Challenge: Manual processing and analysis of incoming lab results was slow, repetitive, and error-prone—consuming valuable time across email chains and spreadsheets.

The Solution: An intelligent document workflow powered by an advanced AI vision model that parses PDF lab reports, automatically translates technical parameters, extracts key metrics, and persists structured results into a central PostgreSQL database.

The Outcome: Real-time lab result analytics, zero manual data entry, and a clean, reliable historical database of water quality metrics—hosted securely inside the client's own AWS account.
